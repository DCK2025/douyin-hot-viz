# 抖音热点 · 结构看板

把抖音热榜的一次快照拆成三个视角：**热度分布**、**类别构成**、**榜单形态**。

在线访问：https://dck2025.github.io/douyin-hot-viz/

## 数据快照

- 榜面时间：约 2026-11-13 00:00
- 条目：20 条
- 类别：时政 / 财经 / 商业 / 娱乐 / 科技 / 情感 / 挑战跟风 / 其他

## 数据说明

- 来源为第三方聚合热榜快照，**非抖音官方实时榜**，有分钟级延迟。
- 热度值为平台综合指数，可横向比较，不等同播放量。
- 第 11–20 位仅获得约 767–773 万的区间，个体数值为区间内估算，页内以「估」标注。
- 类别由人工按标题主属性判定，一条只归一类。

## 技术

单文件 `index.html`，纯 HTML/CSS/JS，无外部依赖、无构建步骤、无第三方字体与 CDN。
推送到 `main` 后由 GitHub Actions 自动部署 Pages。

## 本地预览

直接双击 `index.html` 即可，不需要起服务。
